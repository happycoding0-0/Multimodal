# MultiModal AI

## Goal
1.  what is it? (이게 뭐야?) $\rightarrow$ 답변
2.  사물의 개수 세기 $\rightarrow$ 답변


- Audio : 음성명령 $\rightarrow$ STT 
- Vision : 음성 명령(VAD,STT) $\rightarrow$ 시각정보 수집 $\rightarrow$ 처리
- Brain : LLM
- Speech : result $\rightarrow$ TTS



#### Vision

영상은 이미지의 연속이기 때문에 이미지와 개념이 같음
* 이미지 데이터 구조
    * 색상 채널
        * 흑백: 하나의 채널로 구성된 2차원 행렬, 0(검)~255(흰)까지의 밝기(명암)
        * 컬러: RGB 3개의 채널로 겹쳐진 3차원 행렬, 각 채널별(R,G,B) 0~255의 값 조합으로 다양한 색 표현
    * 픽셀: 이미지를 구성하는 최소단위, 각 픽셀은 색상과 밝기 정보를 숫자로 가짐
    * 해상도 : 가로 픽셀 수 x 세로 픽셀 수로 표현, 숫자가 클수록 더 선명 하고 데이터 용량도 커짐
