# Computer Vision
computer vision is not a single function but a collection of a distinct tasks.
컴퓨터 비전은 단일 기능이 아니라 여러 개별 작업의 집합입니다. 

* Image Classification : assigns a class label to an entire image , answering the question, "What is in this picture?" 전체 이미지에 클래스 라벨을 할당하여 "이 사진에는 무엇이 있습니까?" 라는 질문에 답합니다.
* Object Detection :  detection identifies distinct objects within an image and draws a bounding box around them. This is crucial for counting items or locating specific features. 객체 탐지는 이미지내에서 서로 다른 객체를 식별하고 그 주위에 바운딩 박스(경계상자)를 그립니다. 이는 항목 수를 세거나 특정 객체의 위치를 찾아내는데에 매우 중요합니다.
* Instance Segmentation : This provides a precise pixel-level mask for each detected object, separating individual instances of the same class. It is vital for applications requiring high precision , such as analyzing medical images. 이는 감지된 객체의 정밀한 픽셀 수준 마스크를 제공하여 동일한 클래스의 개별 인스턴스를 구분합니다 . 이는 의료영상 분석과 같이 높은 정밀도가 요구되는 응용 분야에 필수적 입니다 .
* Pose Estimation : This involves detecting specific keypoints on an object , such as the joints of a human body , to track movement and posture. 이는 인체에서 관절 같은 객체의 특정 키포인트를 감지하여 움직임과 자세를 추적하는것을 포함합니다.
